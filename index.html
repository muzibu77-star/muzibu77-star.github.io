宠物意图理解 Agent

深圳市宠智联科技 · 2026.05 – 至今

结合宠物视频和项圈行为记录，回答主人“它这是想干嘛”。

背景SITUATION
主人常看不懂宠物想要什么，而且同一个动作在不同时间意思不同：早上蹲门口多半是要上厕所，下午可能只是想出去玩。只看一段十几秒的视频，看不到这些前因后果。
任务TASK
让 App 结合视频和这只宠物自己的项圈记录判断意图；两边证据对不上时，不能随便给答案。
行动ACTION
  • 微调 Qwen2.5-Omni-7B 做音视频理解，联合训犬师、猫行为分析师复核标注数据。
  • 做项圈六轴行为识别：自监督预训练提升识别效果，量化感知训练后端侧模型仅 21.6 KB；实时识别服务经 MQTT 接入项圈与 App。
  • 用 LangGraph 搭多 Agent 系统：按“拍摄那一刻 / 前后半小时 / 近 7 天”查行为记录，先提候选意图再逐个查证，冲突时向主人追问，对话可跨进程恢复。
  • 证据引用和结论由代码强制校验，用 59 项故障注入测试保证服务稳定。
结果RESULT
+15.6 / +41.2猫 / 狗分类准确率较原厂模型提升（百分点）
全部视频模型单独判错的测试案例，都改为先追问
12 → 1静音下仍“听到”叫声的猫视频（64 条中）
116 / 117多轮测试中 Agent 行为符合预期的轮数

研报数字核查 Agent

2026.03 – 2026.10

研报发出前，把每个数字对回上市公司年报原文。演示稿件为比亚迪 2024 年年报点评。

背景SITUATION
研报里的数字都要能对上年报原文，但质控人手有限、时效又紧。越来越多人用 AI 写稿，写得很流畅，数字却常常是错的：实测不给原文时，模型写的点评里 77%–84% 的数字有错。
任务TASK
发稿前自动核查每个数字，给出原文值和出处页码，并且不能漏掉实质性错误。
行动ACTION
  • 把 30 家上市公司 25,224 页年报解析成 53.7 万条事实，每个数字都定位到 PDF 原文位置；核对时只用写稿日之前已披露的文件。
  • 不让大模型当裁判：模型只负责抽取数字，对错由代码查年报库判定；抽取模型是用 FSDP + LoRA 微调的本地 Qwen3.5-9B，稿件可不出本机。
  • 用 LangGraph 编排抽取、核查、复查、修订四个 Agent；对比实验后规定复查 Agent 只能新增告警、不能放行。
  • 做了人工核查页：点击稿件里的数字，直接打开年报原件并框出出处。
结果RESULT
95.3%封存测试集上的错误召回率
0 vs 111实质性错误漏检（本系统 vs 大模型直接审稿）
2.95%误报率
46 → 7微调后本地抽取模型的误报

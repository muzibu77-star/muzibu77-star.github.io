做事方式

先写判据，再跑实验

采用门槛和判定标准在训练、验收之前写进记录；测试集封存到最后只用一次，结果出来后不再调参。

每个结论配一个对照

LoRA 对比原厂基座、多 Agent 对比单 Agent 与固定流程、静音副本配原样副本对照臂，只改一个变量，小样本配配对检验。

规则落成代码

提示词只能让模型大概率照做；证据编号、引用层级、完成状态这类可判定的规则，都由代码在执行前后强制检查。

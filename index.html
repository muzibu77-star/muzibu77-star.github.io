项目经历

宠物意图理解 Agent

深圳市宠智联科技 · 2026.05 – 至今

融合音视频与项圈六轴时序证据的多模态意图理解系统。

背景SITUATION

宠物行为意图高度依赖时序上下文，同一动作在不同时段语义不同；仅凭十余秒的视频片段，单一视觉模型缺乏判断所需的前因后果。

任务TASK

融合视频理解与个体化的项圈行为记录进行意图推断，并在跨模态证据冲突时保证系统不输出无依据结论。

行动ACTION

  • 基于 Qwen2.5-Omni-7B 原生音视频建模与领域 LoRA 微调，联合训犬师 / 猫行为分析师建立专家复核的标注流程。
  • 构建六轴 IMU 端侧行为识别模型，结合自监督预训练与量化感知训练（QAT），模型压缩至 21.6 KB，经 MQTT 实时识别服务接入项圈与 App。
  • 基于 LangGraph 设计多 Agent 系统，按拍摄时刻、前后时段、近 7 天三层时间窗检索行为证据，采用假设—验证式工具调用，冲突时触发澄清追问，基于 checkpoint 实现跨进程会话恢复。
  • 以代码级输出校验约束证据引用与结论，59 项故障注入测试全部通过。

结果RESULT

+15.6 / +41.2猫 / 狗分类准确率较基座模型提升（百分点）
100%单视频模型误判样本转入澄清追问
12 → 1静音输入下音频幻觉样本数（猫，n=64）
116 / 117多轮评测中 Agent 行为合规轮次

研报数字核查 Agent

2026.03 – 2026.09

研报发布前的数字事实核查系统，逐条溯源至上市公司年报原文。演示稿件为比亚迪 2024 年年报点评。

背景SITUATION

研报数据须与原始披露逐条一致，而质控人力与发布时效双重受限；生成式模型撰写的点评数字错误率在无原文条件下达 77%–84%。

任务TASK

在发布前自动核查稿件中的每个数字，输出原文值与出处定位，并确保实质性错误零漏检。

行动ACTION

  • 基于版面解析与 PDF 文本层对齐，将 30 家上市公司 25,224 页年报构建为 53.7 万条可溯源结构化事实，并按披露日实施时点控制，规避前视偏差。
  • 设计“LLM 结构化抽取 + 规则引擎核验”的混合架构，LLM 仅承担信息抽取，核验结论由确定性规则给出；以 FSDP + LoRA 微调 Qwen3.5-9B 抽取模型，支持本地私有化部署。
  • 基于 LangGraph 编排抽取、核验、复查、修订四个 Agent，经与单 Agent 基线对照，引入复查 Agent 单向告警约束。
  • 构建证据溯源审核页，支持由稿件数字直接定位并框选年报原件出处。

结果RESULT

95.3%封存验收集错误召回率
0 vs 111实质性错误漏检（本系统 vs 端到端审稿基线）
2.95%误报率
46 → 7微调后抽取模型误报数
